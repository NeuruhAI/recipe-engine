
# NC DPS P0 — Recipe Engine Boundary

## Canonical ownership

`recipe-engine` receives a completed, source-linked LandOS property packet and
compares bounded strategies.

It may produce candidates for:

- Whole-property acquisition.
- Fractional-interest acquisition.
- Heir-property joint venture.
- Title cure and resale.
- Stalled tax-case resolution.
- Tax-foreclosure sale bidding.
- Surplus-funds recovery.
- Monitoring.
- Rejection.

## Explicit exclusions

Recipe Engine does not:

- Scrape county systems.
- Own parcel truth.
- Rewrite source evidence.
- Declare legal ownership.
- Declare title clear.
- Exclude possible heirs or interest holders.
- Contact an owner.
- Present an offer.
- Move funds.
- File or record documents.
- Execute a selected strategy.

Every P0 candidate is analytical only and must carry explicit false execution
authority.
